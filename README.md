# OOP-Course-UFES

Labs from the Object-Oriented Programming course at UFES, written in Java and C++.

## Structure

The repository is organized by lab. Each lab is a folder, and each lab is a collection of exercises, with one subfolder per exercise.

```
oop-coursework/
├── lab1/
│   ├── ex1/
│   ├── ex2/
│   └── ...
├── lab2/
│   ├── ex1/
│   ├── ex2/
│   └── ...
└── ...
```

## Topics

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstract classes and interfaces
